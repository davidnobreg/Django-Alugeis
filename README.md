# Django Alugeis

Projeto de estudo desenvolvido durante o aprendizado de Django. Implementa um CRUD básico para gerenciamento de alugueis de imóveis.

## Funcionalidades

- Cadastro de imóveis
- Cadastro de inquilinos
- Registro de alugueis
- Listagem e edição de registros

## Stack

- Python
- Django
- SQLite

## Como rodar

```bash
# Clone o repositório
git clone https://github.com/davidnobreg/Django-Alugeis.git
cd Django-Alugeis

# Instale as dependências
pip install -r requirements.txt

# Rode as migrations
python manage.py migrate

# Inicie o servidor
python manage.py runserver
```

Acesse em `http://localhost:8000`
